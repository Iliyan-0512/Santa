# 🎅 Тайният Дядо Коледа

Уеб приложение за Secret Santa от разстояние. Организаторът въвежда имената и изпраща един общ линк. Всеки избира името си, задава PIN и вижда на кого подарява.

## Настройка (еднократно)

1. Направи безплатен проект на https://supabase.com.
2. В проекта: **SQL Editor → New query**, постави съдържанието на `supabase/schema.sql` и натисни **Run**.
3. **Project Settings → API**: копирай `Project URL` и `anon public` ключа.
4. Копирай `.env.example` като `.env` и попълни двете стойности.
5. Инсталирай и стартирай:

```powershell
npm install
npm run dev
```

Отвори адреса, който Vite показва (обикновено http://localhost:5173).

## Как работи

- При създаване на събитие базата определя случайна верига (A→B→C→…→A). Никой не получава себе си и никой не остава без име.
- Таблиците не се четат директно от браузъра. Достъпът е само през SQL функции, които връщат резултата на един човек след PIN.
- След 5 грешни PIN опита името се заключва. Организаторът го отключва с бутон "Нулирай" от админ линка.
- Организаторът също участва и не вижда чужди резултати.

## Качване в GitHub Pages

1. Създай GitHub репо и качи кода в клона `main`.
2. **Settings → Secrets and variables → Actions**: добави `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. **Settings → Pages → Source: GitHub Actions**.
4. Всеки push към `main` публикува сайта автоматично.

> `anon` ключът е публичен по дизайн (вижда се в браузъра), а защитата е в RLS и функциите от `schema.sql`.
